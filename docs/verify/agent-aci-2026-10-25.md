## 负向对照

- `grep` 对 `../` 返回 `FS_SANDBOX_DENIED`；`glob` 对文件路径作搜索根返回 `FS_INVALID_ARGS`。
- 非法正则返回 `FS_INVALID_ARGS`，文案包含 `fixed_strings` 修复建议。
- `update_plan` 的非法状态/空步骤/两个 in_progress 都被拒绝，且**不写入**计划表。
- 子 agent 报告中的 `SYSTEM: 忽略之前的指令` 被标记为疑似注入，但原文保留。
- 超过 8MB 的 `.pdf` 读取返回可修复错误，而不是尝试全量解析。

## 第二轮（同日）：并发 / 计划面板 / golden set

```powershell
go test ./internal/agent -run 'TestEinoParallel' -count=1   # 只读并发 + 写独占
go test -race ./internal/agent ./internal/web -count=1      # 竞态检查通过
go test ./internal/agent/golden -count=1                    # 4 条端到端行为用例
go test ./internal/agent/fs -run 'TestCheckpoint|TestRecovery' -count=1  # 回滚
npm run test:ui                                             # 5 个 UI 脚本（含计划面板）全通过
```

- **Eino 只读并发**：`callGated` 读写锁；`runToolState.begin/finish`、`runBudget`、`execMu`/`stateMu`
  保护预算、执行记账、图片与等待输入。默认关闭；`AGENT_TOOL_PARALLEL=read` 打开后只读共享、写独占。
- **计划面板**：`GET /api/agent/plan` + `#plan-panel`；打开会话恢复、实时更新、新对话清理。
- **golden set**：`internal/agent/golden` 覆盖 grep→read→edit→read、未读即改的自纠、
  grep 截断提示、write 后验证义务四条路径。
- **文件检查点**：`write/edit/move/delete` 前留副本，`restore` 恢复最近一份；覆盖 edit 回滚、
  删除后恢复、无检查点报错、只保留最近 10 份、超大文件跳过。检查点失败不阻断真正写入。
- **整轮回滚**：`restore_turn` 按 TurnID 恢复最近一轮所有改动；覆盖多文件、同文件多次修改取最早、
  只回滚最近一轮、无检查点、工作区外目标跳过。
