# 雾面主题与交互性能调整（2026-10-16）

## 已落地

- 按用户追加偏好，日间改为低饱和雾蓝、夜间深蓝；语义配色覆盖聊天、设置、卡片、表单和弹层。
- 侧栏、输入框与浮层使用有色半透明；正文不模糊。背景为双色环境光、淡弧线和少量星点，柔光仅做 36 秒缓慢位移，星点以透明度和小幅位移变化；后台和减少动态效果设置下暂停。首屏月牙动画关闭。
- 首次未保存主题时跟随系统深浅偏好；保留旧主题存储键和用户已保存的选择。
- 中等窗口模式按钮收成图标，并保留名称和悬浮提示；窄窗口工具栏允许换行。
- 统一刷新调度器：后台暂停、返回补拉、同一任务等待上次完成后再计时；切出聊天页暂停团队与子任务刷新。
- 相同 GET 请求合并进行中的请求；团队数据不变时不重建成员列表，暂时网络错误保留上一次团队内容。
- 消息接口增加 `limit`、`before` 游标，默认新客户端取最近 60 条，单页最多 200 条；旧客户端不传参数时仍返回数组。
- 更早历史按需追加，保留阅读锚点；已有消息 ID 保持稳定，新增消息按角色和原文匹配，不按分页后的数组下标匹配。
- 最近会话缓存继续使用；旧请求返回时检查会话与请求序号，避免覆盖新页面。
- 历史节点使用浏览器离屏内容跳过绘制；提示词库推迟到空闲时加载，助手列表不阻塞首屏初始化。
- 本地性能记录最多 200 条，记录网络请求、历史渲染、切页等待与可用浏览器的长任务；通过 `APP_PERF.snapshot()` 查看，不向外发送。
