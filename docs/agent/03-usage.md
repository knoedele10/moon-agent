# Agent 使用与执行约束

本页对应 2026-10-19 整理后的源码。2026-10-12 的早期验收快照已移至 [历史记录](../archive/agent-usage-2026-10-12.md)；旧文档中的代码位置和行号仅代表当时状态。

## 启用

桌面版默认启用工具。HTTP 请求需满足服务端 `AGENT_TOOLS` 开启且请求 `tools: true`；普通聊天仍可关闭工具。文件操作需要已配置并存在的工作区。会话用途先筛选能力，再由执行模式与具体工具校验权限。

```json
{"model":"已配置的模型名","content":"创建笔记并读回确认","tools":true,"execution_mode":"auto"}
```

## 三种模式

| 模式 | 行为 |
| --- | --- |
| `plan` | 规划；工作区内仅可写 `.md` 存档，不提供通用命令执行；计划写入越界直接拒绝 |
| `confirm` | 风险工具先返回确认请求；用户确认后才执行 |
| `auto` | 自行决定常规细节并执行；必要信息、访问权限等真实阻碍仍可提问 |

本次请求中的 `execution_mode` 优先于助手预设。工作、代码会话有工作区时可使用命令工具，命令自身仍检查程序白名单与工作目录。子 Agent 继承模式限制；无法自行确认的风险操作交回主会话。工具选择和包装集中于 `internal/web/agent_tool_policy.go`。

## 多工作区和文件操作

活动目录保存在用户的 Agent 设置中，由 `internal/agent/fs/` 与 HTTP 路径包装器解析。相对路径默认指向主工作区，额外工作区别名需要先解析成实际根目录；不能把别名当成技能子目录。工作区外的绝对路径会按执行模式处理。编辑已有文件前需要读取观察版本，版本不匹配时拒绝覆盖；文件落盘使用原子写入规则。

## 执行预算与流式结果

默认每阶段 32 轮模型调用、96 次工具调用；自主模式默认再允许 2 个续行阶段。分别通过 `AGENT_MAX_ITERATIONS`、`AGENT_MAX_TOOL_CALLS`、`AGENT_LIMIT_RECOVERY_ROUNDS` 调整。达到最终预算后整理已执行结果并标记 `incomplete`，不宣称任务完成。详见 [运行器说明](08-eino-runtime.md)。

SSE 事件包括文本增量、工具调用、工具结果、需要输入与完成事件。工具调用与结果必须一一配对，即使调用被拒绝也返回结果。前端可展开详情，触顶显示暂停状态。

两种运行器共享 `internal/agent/tool_state.go`：只读暂时错误至多重试一次；非幂等操作结果未知时阻止后续重复副作用；成功修改后要求验证。等待用户输入、取消、运行超时与权限限制仍会停止当前执行。

## 记忆、画像与人格

知识库入库与召回在 `internal/rag/`，通过 HTTP 层把相关记忆放入模型上下文。检索失败可降级，避免阻断主对话。用户画像的构建与注入在 `internal/web/agent_profile.go`，人格及助手设置保存在 `internal/model/` 对应模型。用户画像是否已有内容应查询当前数据库，不能只根据代码存在就判断已生成。
