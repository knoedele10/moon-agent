# Day 14 轻量用户测试清单

> 目的：让一位真人按这份清单操作你的页面，记录他第一反应找不到/卡住的地方，再做一次最小修复。
> 测试对象：http://localhost:8091/chat（多模型对话站，第 2 周做的三个视图）。

## 给测试者的话
请用你自己的话把每一步"卡在哪"说出来，不要怕说"我不知道点哪"。每步完成后，把感受写在右边一栏：
- 顺利 → 打 ✓
- 卡住 → 写"找了一会儿，先点了 X 才发现"
- 找不到 → 写"完全没找到这个功能"
