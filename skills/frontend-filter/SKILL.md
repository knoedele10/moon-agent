# frontend-filter：筛选类交互规范

## 什么时候用
在聊天页新增任何"按条件过滤列表"的功能（搜索、筛选、标签过滤）之前，读这个文件。

## 设计规则（源自 Day 9 前端审查，必须遵守）
1. 文字对比度 ≥ 4.5:1；次要文字只用 `--text-faint`，不自己发明灰色。
2. 间距只落在 4 / 8 / 16 / 24 / 32 档位上，不出随机数。
3. 筛选输入框左右边缘与侧栏其他内容（品牌行、会话条目）对齐，内边距 16px。
4. 反馈发生在动作发生的地方：筛选无结果时，提示必须出现在列表区域内，不能只弹 Toast。
5. 输入框必须有可见的焦点样式（复用 `.input:focus` 的描边 + 光晕），键盘 Tab 能到达。
6. 筛选纯前端完成，不重新请求 API。

## 筛选必须支持的三种状态
1. **有结果**：只显示标题包含关键词的会话，其余隐藏。
2. **无结果**：列表区域显示"没有找到匹配「关键词」的会话"，不允许留空白。
3. **清空恢复**：输入框清空后立刻恢复完整列表，提示消失。

## 自查清单（实现完逐条打勾）
- [x] 输入关键词，列表实时过滤且不重新请求接口
- [x] 无结果时列表区域出现文字提示
- [x] 清空输入框立即恢复全部会话
- [x] 连续输入、删除、清空不出错（可用 DevTools 或自动化连续操作验证）
- [x] 输入框 Tab 聚焦有可见焦点样式
